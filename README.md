# 🍔 SnapBite — Restaurant Website

A modern and responsive restaurant website built with **HTML, CSS, and JavaScript**, featuring dynamic page views, a data-driven menu, reservation form validation, and responsive layouts.

This project was built as part of **The Odin Project** to practice JavaScript modules, DOM manipulation, Webpack, and building a multi-view website from scratch.

## 📂 Project Structure

- `src/index.js` — Application entry point and navigation
- `src/template.html` — Webpack HTML template
- `src/modules/home.js` — Home view
- `src/modules/menu.js` — Data-driven menu view
- `src/modules/contact.js` — Contact and reservation view
- `src/styles/style.css` — Responsive visual styling
- `webpack.config.js` — Webpack configuration

## 🎯 How It Works

SnapBite uses JavaScript modules to separate different parts of the application.

### 🏠 Home

Introduces the SnapBite restaurant and provides the main navigation experience.

### 🍔 Menu

Menu content is generated dynamically from JavaScript data rather than being manually repeated in HTML.

### 📬 Contact

Includes contact information and a reservation form with browser-side validation and confirmation feedback.

## 💻 Run Locally

### Requirements

- Node.js
- npm

### Installation

Clone the repository:

    git clone https://github.com/snehavyas-dev/snapbite-restaurant-website.git

Navigate to the project:

    cd snapbite-restaurant-website

Install dependencies:

    npm install

Start the development server:

    npm start

Then open the local development URL provided by Webpack Dev Server in your browser.

## 🏗️ Production Build

To create a production build:

    npm run build

Webpack generates the deployable files inside the `dist/` directory.

## 🚀 Deployment

The project is deployed using **GitHub Pages**.

To deploy:

    npm run deploy

Live website:

https://snehavyas-dev.github.io/snapbite-restaurant-website/
